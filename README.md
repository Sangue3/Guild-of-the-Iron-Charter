# Guild of the Iron Charter

A dark fantasy idle auto-battler: lead a guild of mercenaries from rank F to rank S.

**Play in the browser:** https://sangue3.github.io/Guild-of-the-Iron-Charter/

Progress is saved in your browser. To carry it to another device, use the transfer button
(the two arrows, top right) to create a code there and import it on the other device.

This repository only holds the published build.
